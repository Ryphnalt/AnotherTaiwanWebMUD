# 平行時空的台灣 WebMUD 教學指引

## 基本指令

### 移動
- `n` 或 `north` - 向北
- `s` 或 `south` - 向南
- `e` 或 `east` - 向東
- `w` 或 `west` - 向西
- `nw` 或 `northwest` - 向西北
- `ne` 或 `northeast` - 向東北
- `sw` 或 `southwest` - 向西南
- `se` 或 `southeast` - 向東南

### 其他指令
- `look` 或 `l` - 查看當前房間
- `hp` 或 `score` - 查看狀態
- `save` - 存檔（在圓山飯店使用）

### 如何加入公會
1. 前往對應的公會位置
2. 確認符合加入條件
3. 輸入 `join <公會代碼>` 加入

### 公會列表
- `join adventurer` - 探險者公會
- `join scholar` - 書生公會
- `join thief` - 盜賊公會
- `join healer` - 醫生公會
- `join knight` - 騎士公會
- `join magician` - 魔法師公會
- `join monk` - 和尚公會

### 公會指令
- `guilds` - 查看所有公會及其位置和加入條件
- `guild` 或 `guildinfo` - 查看當前公會信息
- `leave` - 退出當前公會

## 💡新手指南

### 開始遊戲
1. 輸入角色名字
2. 選擇種族 (human/elf/dwarf/orc/demon)
3. 在圓山飯店開始冒險

### 基本流程
1. 使用 `look` 查看周圍環境
2. 使用方向指令移動 (n/s/e/w)
3. 前往訓練場練習戰鬥
4. 加入公會學習技能
5. 探索世界，完成冒險

### 重要提示
- 記得定期在圓山飯店使用 `save` 存檔
- 死亡會損失一半經驗，並復活在圓山飯店
- 輸入 `help` 查看所有指令
- 輸入 `guilds` 查看公會信息
